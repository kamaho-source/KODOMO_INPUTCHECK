# Backlog のチケット（課題）を検索・一覧する

チャット入力の **このコマンド名の後ろに付けた引数**（検索条件）を最優先で使う。

## 引数

| 位置 | 例 | 意味 |
|------|-----|------|
| 1 | `自分の未完了チケット` | 検索条件（自然文可。無ければ「未完了・自分担当」をデフォルトにする） |

例: `/ticket-list 自分の未完了チケット` / `/ticket-list SHOKUSU プロジェクトの今週更新分`

## 必ず行うこと

1. Skill / 手順の正本に従う: `skills/backlog-tickets/SKILL.md`
2. MCP `get_issues`（必要なら `count_issues` で件数確認）で条件に合う課題を取得する
   - 担当者・ステータス・プロジェクト・キーワードなど、指定された条件をパラメータに反映する
3. 課題キー・件名・ステータス・担当者・URL を一覧で報告する

## 禁止

- 取得件数が多い場合に絞り込みなしで全件出力すること（条件をユーザーに確認する）
- API キーを出力すること
