# Backlog のチケット（課題）を更新する

チャット入力の **このコマンド名の後ろに付けた引数**（課題キーなど）を最優先で使う。

## 引数

| 位置 | 例 | 意味 |
|------|-----|------|
| 1 | `SHOKUSU-13` | Backlog 課題キー（必須。無ければユーザーに確認） |
| 2 | `ステータスを処理中にする` | 更新内容（ステータス・担当者変更、コメント追記など。無ければユーザーに確認） |

例: `/ticket-update SHOKUSU-13 ステータスを処理中にして担当者を大橋にする`

## 必ず行うこと

1. Skill / 手順の正本に従う: `skills/backlog-tickets/SKILL.md`
2. **課題取得**（必須）: MCP `get_issue` で現在の状態を取得してから更新する
3. MCP `update_issue` でフィールドを更新する。コメントのみの追記は `add_issue_comment` を使う
4. **完了（Closed）にする・削除するなど元に戻しづらい変更は、ユーザー確認後のみ**実行する
5. 更新後の状態と課題 URL を報告する

## 禁止

- 課題未取得のまま更新すること
- 完了・削除など不可逆的な変更を確認なしに行うこと
- API キーを出力・コミットすること
